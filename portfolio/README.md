# Megersa Bekele — React Portfolio

A modern, responsive developer portfolio built with React and Vite.

## Tech
- React
- Vite
- CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Customize

Open `src/main.jsx` and update:
- `githubUrl`
- `linkedinUrl`
- `email`
- Projects
- Skills
- Education

Replace the LinkedIn placeholder with your real LinkedIn URL:

```js
const linkedinUrl = "https://www.linkedin.com/in/your-username/";
```

## Build for production

```bash
npm run build
```
